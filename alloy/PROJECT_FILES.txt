SETUP INSTRUCTIONS
==================

Quick Start:
  1. Run: ./setup.sh
  2. Configure backend/.env with Alloy credentials
  3. Run: ./start-backend.sh (Terminal 1)
  4. Run: ./start-frontend.sh (Terminal 2)
  5. Open: http://localhost:3000

Manual Setup:
  Backend:
    cd backend
    python3 -m venv venv
    source venv/bin/activate
    pip install -r requirements.txt
    # Create .env file with credentials
    python app.py

  Frontend:
    cd frontend
    npm install
    npm start
